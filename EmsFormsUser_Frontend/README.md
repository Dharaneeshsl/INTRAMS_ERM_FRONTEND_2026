# INTRAMS ERM - User Frontend

React / Vite frontend application for event organizers to submit and update event forms.

## Features
- Interactive 5-step event proposal wizard (Instructions, Event Details, Description & Schedule, Rounds & Rules, Items & Review).
- Real-time step validation and session persistence.
- Event management & status tracking.

## Development
```bash
npm install
npm run dev
```

App runs at `http://localhost:3000`.

## Build
```bash
npm run build
```
