# INTRAMS ERM - Admin Frontend

React / Vite admin portal for managing event proposals, club credentials, inventory stocks, item allocation, edit access permissions, and role-based PDF reports.

## Features
- Multi-role dashboard (Admin, Member, Procurement).
- Club user management & access token controls.
- Stock allocation & item grant tracking with rollback history.
- PDF generation & downloading for event summaries and procurement lists.

## Development
```bash
npm install
npm run dev
```

App runs at `http://localhost:5173`.

## Build
```bash
npm run build
```
